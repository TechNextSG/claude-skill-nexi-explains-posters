# nexi-explains-posters

Design cinematic, one-of-a-kind promo posters (3:4 social images; posters only, no video) for TechNext's animated YouTube series "Nexi Explains" - one poster per episode, Quick Tip or holiday special, each built from that episode's own world (its sets, props, cast, Nexi's costume, the big moment) with its own poster genre, camera, light, type treatment and signature cinematic device, never a shared template. Covers the episode catalogue and premiere dates, borrowing the films' real art (painters, 3D Nexi renders), the uniqueness register, captions and delivery to the Marketing drive. Use whenever the user asks for a Nexi Explains poster, an episode promo, a premiere announcement, "promotion per episode", social posts about a Nexi episode/season/quick tip, or full marketing for the Nexi series - even if they only say "make the EP05 post".
